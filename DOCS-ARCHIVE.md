# Local React documentation archives (experimental)

This candidate builds the full repository-local React gallery at `/docs/v/<framework-version>/`, pins the exact published core version and registry integrity, injects a version navigation with plain-link fallback, and records per-file SHA-256 digests. A caller supplies a separately authenticated baseline catalog and its SHA-256; local creation verifies prior manifests and bytes and refuses a second write to the same version. The catalog and latest pointer are never promoted by this command. Archive pages are noindex pending a real canonical URL policy. The frozen shared recipe snapshot and exact source commit are recorded in each manifest.

From a clean Git checkout with Node 24 and npm, prepare an archive directory and a baseline catalog. Set `RELEASE_TAG`, `DOCS_ARCHIVE_ROOT`, `DOCS_BASELINE_PATH`, and the SHA-256 `DOCS_BASELINE_SHA256`; optionally set `DOCS_DEPLOY_PREFIX` to a safe absolute path such as `/preview`. Run `node scripts/docs-versions/build-release.mjs`. The builder exports the committed tree, performs `npm ci --ignore-scripts`, builds all 50 gallery routes with the archive base, and creates a local snapshot. Archive creation and history must be exercised before use; no live deployment or publication is performed.

The local no-clobber reservation does not establish remote immutability. Authenticated create-only remote storage, independently trusted catalog history, stable serving, latest-stable promotion, recovery and rollback must be integrated and independently verified before enabling the separate tag release. Its documentation gate remains deliberately closed. Manual assistive-technology and physical-device assessment remain outstanding.
