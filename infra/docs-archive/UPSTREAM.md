# Upstream archive protocol

This nonproduction React-specific adaptation derives from the Astro combined archive proposal at `martletdesign/astro` commit `7a3d8c97071cdc88965d8a565946d968ddd7f350`, which uses the shared workbench documentation contract. It changes the framework namespace and exercises actual React snapshot manifests. Reconcile future security fixes with the shared protocol; this is not an independent authority for the archive contract. Remote immutable storage and externally protected checkpoints remain unproven.
