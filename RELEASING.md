# Release preparation (inactive)

The source remains private and this repository has no publishing workflow. The portable release guard is shared in structure with the Astro release candidate; it validates protected tag event and remote tag identity, production first-parent ancestry, source/manifest/lock identity, exact core dependency, registry status, artifact bytes and verified provenance. Its unit tests include negative cases. A standalone archive and source control policy, the production release workflow, OIDC configuration, independently verified historical documentation, and a separately reviewed publication-authority handoff are still required. The existing workbench publication path remains unchanged. No npm publish is permitted by this proposal.

An eventual versioned documentation snapshot must use this framework's own release tag, record the exact core version and registry integrity, and use create-only remote storage with a separately verified catalog and pointer. The browser fixture is a test, not the full reference site. Do not activate release publication until archive storage, history, serving, rollback, and recovery have been implemented and verified. A protected reviewed Git tag is the routine authorization; no duplicate per-release approval gate is proposed.
