# Reference gallery extraction

This editable gallery, shared catalog/model snapshots and fixture assets were copied from `k3jph/design-workbench` commit `04d3e14b1b1943cbf2a90f1a727822d87327b2ae`, itself a descendant of frozen Nightjar II `80a5635abe4de7a07a1983de0b3ef796b101e047`. The canonical shared recipes remain maintained in the workbench; the checked-in files here are a pinned snapshot for an independently buildable framework reference site, not a new canonical catalog authority. Changes to shared recipes should be reconciled with that authority and re-snapshotted with provenance.

The gallery uses this repository's React sources and the exact published `@martlet/core` dependency. It makes no request to the workbench during build or at runtime. The experimental scientific workspace and three dashboards are included alongside 50 content routes. No deployment, publication or documentation archive is performed.
