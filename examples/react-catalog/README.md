# Martlet React reference gallery (experimental)

This editable source snapshot builds the 50 canonical examples, three dashboards and scientific workspace independently. Run `npm ci --ignore-scripts`, `npm run build`, then `npm run build:gallery` from the repository root. Set `NIGHTJAR_BASE=/preview/` for a subpath build; output is `examples/react-catalog/dist/martlet`. Use Node 24.19.0.

The 50 recipes and shared models are attributed, pinned snapshots; see PROVENANCE.md. Source is prerendered into HTML, with interaction progressively enhanced. The gallery is experimental: complete visual and interaction parity, manual assistive-technology and physical-device checks, immutable documentation archives, and deployment are outstanding. Do not treat it as a production deployment or independently authoritative catalog.
