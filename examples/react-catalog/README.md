# Martlet React reference gallery (experimental)

This native reference builds a real homepage at `/`, the separate 50-example library at `/examples/`, three dashboards and the scientific workspace independently. Run `npm ci --ignore-scripts`, `npm run build`, then `npm run build:gallery` from the repository root. Set `NIGHTJAR_BASE=/preview/` for a subpath build; output is `examples/react-catalog/dist/martlet`. Use Node 24.19.0.

The 50 recipes and shared models are attributed, pinned snapshots; see PROVENANCE.md. Source is prerendered into HTML, with interaction progressively enhanced. The corresponding Jekyll v1.1.0 reference is the visual authority. Canonical source styles, local fonts and approved responsive imagery are attributed in CANONICAL-SOURCE.json; the page templates, hydration and state remain native React. The shipped package API remains experimental. Manual assistive-technology and physical-device coverage is separate from automated checks. Current reference pages identify their accepted source commit; versioned documentation retains its protected release source, and the advanced remote archive remains disabled.
